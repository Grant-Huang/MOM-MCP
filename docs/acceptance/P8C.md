# P8C 公共工序 · 查询与派工队列

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P8C-01 | 在 CNC 和按单装配分别查询工序、下达、派工并推进作业 | 两种工艺共用查询契约；下达前队列为空，前序阻塞可查，派工后退出队列，终测按测试台及优先顺序显示，查询保持游标 |

P8C-UI 通过真实浏览器 HTTP 桥与 MCP 读取 CNC 工序，验证下达后进入工作中心队列、暂停后移出及恢复后重新进入。

通过 `npm run acceptance -- P8C --gate` 运行当期切片与 P0–P8B 回归。P8C 剩余公共动作、资源互斥、实绩及默认模拟停机处置以随后增加的可执行用例签收。

cnc@10 和 assembly@10 开放公共只读工具。list_operations 按工序顺序返回工单全路线。get_operation 返回同一结构的指定工序。list_dispatch_queue 返回 ready 项，按优先级降序、交期和工单编号排序，可按确定的工作中心过滤。队列保留已有阻塞的等待项并显示原因，资源尚未分配时工作中心可为空。三项读取均不推进业务游标或仿真时间。现有工艺专用写入口继续决定实际执行结果。
