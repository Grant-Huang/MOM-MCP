# P8C 公共工序 · 查询与派工队列

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P8C-01 | 在 CNC 和按单装配分别查询工序、下达、派工并推进作业 | 两种工艺共用查询契约；下达前队列为空，前序阻塞可查，派工后退出队列，终测按测试台及优先顺序显示，查询保持游标 |
| P8C-02 | 在 CNC 和装配查询资源能力、提高第二张工单优先级，分别尝试错派、过期派工和有效派工 | 队列反映优先级，拒绝不推进游标，CNC 停机时不可派工，成功后可幂等重放并查询已派状态 |
| P8C-03 | 两连接并发争抢资源，并对可用和被占用的目标执行改派 | 同一资源只归一个工单；失败保留原占用；成功释放原资源，目标显示新占用；取消未开工工单释放资源 |
| P8C-04 | CNC 和装配工序开工、暂停、阻止实绩、按有效游标继续作业 | 暂停保持资源占用，重试保留原收据，过期恢复拒绝，最终实绩释放资源 |
| P8C-05 | 分笔报工、确认完工、冲销后补报，并尝试冲销已进入下游的记录 | 报满保持资源占用，确认完工才推进；冲销回补并保留原实绩，序列号不复用；已派工下游阻止冲销，已提交命令可复查 |
| P8C-06 | 装配构建报工、工序完工、测试前冲销、补报，再尝试测试后冲销 | 同名契约可复用，报工后继续占用工位，完工才开放终测，冲销回补物料并保留原件明细，开测阻止冲销 |

P8C-UI 通过真实浏览器 HTTP 桥与 MCP 读取 CNC 工序，验证下达后进入工作中心队列、暂停后移出及恢复后重新进入，并在查询资源和设置优先级后执行错派拒绝、正确派工和改派后的占用核对。

通过 `npm run acceptance -- P8C --gate` 运行当期切片与 P0–P8B 回归。P8C 剩余公共动作、资源互斥、实绩及默认模拟停机处置以随后增加的可执行用例签收。

cnc@10 和 assembly@10 开放公共只读工具。list_operations 按工序顺序返回工单全路线。get_operation 返回同一结构的指定工序。list_dispatch_queue 返回 ready 项，按优先级降序、交期和工单编号排序，可按确定的工作中心过滤。队列保留已有阻塞的等待项并显示原因，资源尚未分配时工作中心可为空。三项读取均不推进业务游标或仿真时间。现有工艺专用写入口继续决定实际执行结果。

cnc@11 与 assembly@11 开放资源能力和公共派工优先级。优先级为 0–9，写入需要业务游标与幂等键。新版公共派工需指定工序、工作中心、业务游标和幂等键。CNC 按下达时冻结的工作中心核对能力和实时门禁。装配 build 核对配置和物料齐套，final_test 使用现有队列开测入口。资源查询可观察装配测试台当前占用。公共派工提交确认分配，统一占用互斥与改派从 v12 开放。历史版本保留原有调用参数。

cnc@12 与 assembly@12 开放 reassign_operation。改派须在已派工且尚未开工时提交，校验目标兼容性、占用、游标和幂等键。CNC 采用冻结的路线和该工作中心的候选替代设备，装配按工单配置判定候选工位。派工与改派在 SQLite 写事务内占用目标，成功改派同时释放原资源，暂停保留占用，取消未开工工单或工序完成后释放。CNC 回退将重新占用原工作中心，原资源忙时拒绝冲销。旧版本维持历史派工行为。

cnc@13 和 assembly@13 支持公共开工、暂停与恢复。写入使用业务游标与幂等键。暂停期间保留占用并阻止实绩，恢复复查适用门禁。装配本批覆盖 build 工序，终测仍走现有测试台流程。

cnc@14 开放公共实绩登记、按工单与工序查询、冲销、显式工序完工及按幂等键查询提交结果。分笔报工和完工分别提交，完成前资源保持占用。冲销保留原实绩、只回补对应投入；已有下游派工或较新有效实绩时拒绝。装配构建共用上述契约，终测实绩仍由现有测试台流程处理。

assembly@14 对 build 工序开放同一实绩契约。单件装配按实际 BOM 扣料并记录配置中的整机序列号，冲销和补报仍对应同一工单和整机身份。原报工 ID 与组件数量保留。开测前的冲销可重新占用原工位，已有占用时拒绝。浏览器验收包含装配报工与终测队列门禁。
