# P9A 版本化主数据

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9A-01 | 在 CNC 和装配创建并启用检验规格，建检验单，再启用新版 | 草稿和旧版不可用于新检验单，已建单继续使用原规格；拒绝修改单位、限值或漏测；不同运行隔离 |
| P9A-UI | 在 CNC 验收台启用规格并创建检验单 | 可查看绑定的规格和限值，过期规格和错误测量参数可见地被拒绝 |

cnc@19 和 assembly@18 开放 `create_inspection_plan_revision` 和 `activate_inspection_plan_revision`。规格由计划编号、正整数版本及 1–100 个检验特性构成，每个特性定义单位和包含边界的上下限。版本内容在创建后固定。同一运行内每项计划只有一个当前版本，只能向更高版本切换。建单使用 `计划编号@版本` 引用当前版本。已有检验单保留原定义，并要求全部定义特性完成测量。复检可使用已失败的同工单检验单作为 `reinspection_of`，继续依据其原版本登记。

规格暂绑定检验单。物料、BOM 和工艺路线版本见下文，后续切片接入工程变更和工单下达快照，再验证整个 P9A。使用 `npm run acceptance -- P9A` 运行本切片和前序回归。

## 物料版本

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9A-02 | 创建物料和两版定义，启用新版并从第二个连接查询 | 单位及范围校验；同一物料只有一个当前版，旧定义保持可查；重试保留原收据，不同运行隔离 |
| P9A-03 | 在装配验收台创建物料和版本并启用 | 可发现命令，可读取版本及当前状态，非法单位被拒绝 |

cnc@20 与 assembly@19 开放物料创建、按编号分页、详情查询、版本创建及查询，以及 `activate_revision` 的物料分支。库存基本单位在物料创建时固定，支持 `each`、`mm`、`m`、`g`、`kg`、`ml` 和 `l`。版本编号为正整数，版本名称在创建后固定，启用只能向更高版本切换。历史版保留原内容。BOM 将引用明确的物料版本。

## BOM 版本

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9A-04 | 在 CNC 和装配创建 BOM，配置组件、校验、启用新版 | 引用明确物料版本，数量和单位正确；拒绝直接及级联循环；新版启用后仍能读取旧版；启用后组件固定 |
| P9A-05 | 在装配验收台配置并启用 BOM | 可查看固定组件版本与单位；错误单位被拒绝 |

cnc@21 与 assembly@20 开放 BOM 创建、读取、组件设置及校验，并在 `activate_revision` 中增加 `bom` 分支。每版 BOM 绑定根物料的同编号版本，组件明确指定物料版本及其库存基本单位。组件设置整体替换草稿，可用 `expand_bom` 明确引用组件的同版本 BOM。启用时根和组件物料版本须已发布，展开的子 BOM 也须已发布。已发布含当前和历史版本。复用旧版不会把依赖改绑到当前版本。计划中的工单快照与 BOM 领料联动分别由后续切片完成。

## 工艺路线版本

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9A-06 | 在 CNC 和装配配置路线、校验并启用新版 | 拒绝未知前序和循环依赖，顺序可重现；启用后工序固定，旧版可查 |
| P9A-07 | 通过浏览器配置、校验和启用路线 | 真实 MCP 返回前序错误与已发布路线的执行顺序 |

cnc@22 与 assembly@21 开放 `create_route_revision`、`get_route_revision`、`set_route_operations`，并在校验与启用命令中增加 `route` 分支。路线绑定根物料的同编号版本。草稿可整体替换工序，每项工序指定工作中心及直接前序。前序须属于同版路线且不能形成循环。服务端按拓扑关系生成顺序，同等就绪时按工序编号排序。启用须有至少一项工序且根物料版本已发布。启用后工序固定，旧版本可查。工作中心的能力及可用性仍由工单执行流程校验，路线和 BOM 的联合下达快照留待下一切片。

本切片通过公开 MCP 枚举 53 个已发布场景版本，`search_tools` 返回 101 个去重业务工具，逐项可读取契约。相比合并基线增加 3 个工具名。另有 8 个公开网关方法。可信控制方法和独立探针未计入业务目录。

## 工单下达快照

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9A-08 | 在 CNC 和装配预检并下达工单，启用新版后读回并评估影响 | 快照固定物料、BOM、路线和检验规格；预检后发生版本漂移时拒绝下达；重试和重连保留原快照 |
| P9A-09 | 在验收台读取已下达工单的快照和工程变更影响 | 浏览器通过真实 MCP 看到冻结版本、当前版本及变化字段 |

cnc@23 与 assembly@22 用 `definition_selection` 选择物料及检验计划。预检解析当前版本，只有同版物料、BOM、路线及启用的检验规格都存在才返回快照指纹。下达在写事务内重算指纹，漂移返回 `SNAPSHOT_CHANGED`。下达记录、快照和幂等收据原子提交。新版检验绑定其工单的冻结规格。工程变更评估比较同一工单的冻结定义与当前定义。该切片开放单笔下达，历史场景保留原单笔与批量下达。生产执行仍复用既有工艺与库存适配，后续切片验证快照驱动实绩及库存联动。

本切片公开 MCP 目录覆盖 55 个已发布场景版本，共 103 个去重业务工具，新增工单快照查询与工程变更评估。另有 8 个公开网关方法。该统计来自运行时发现及契约查询。
