# P9D 在制、质量联动与谱系

## 机加工报工生成在制产出

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9D-01 | 两笔部分报工、幂等重试、在制分页、冲销和质量冻结 | 每笔有效报工产生唯一在制批次。批次可查实投及序列号，重试无重复产出，无额外库存扣减。冲销记录保留，质量冻结反映在活动在制状态。工单范围隔离，重连后结果一致。 |
| P9D-UI | 在浏览器按工单读取实际产出，再冲销报工 | 工具可搜索、调用，返回原报工、序列号和实投。冲销后可按批次查询历史。 |

`cnc@35` 对已提交的机加工报工投影在制批次。报工编号也是该批次的稳定编号。查询使用 `get_wip`，可按工单批量查、按批次精确查，批量查询按批次编号升序分页。产出单位为件。当前状态区分可用、冻结、报废和冲销；同一报工的原始实投和序列号始终保留。

使用 `npm run acceptance -- P9D --gate` 运行本切片和前序累计门禁。跨工序移动、在制拆合、消费依赖、前向与反向谱系、完工入库和工单对账属于后续切片。P10 准出依旧以同一运行的综合用例为准。

运行时工具搜索核对 73 个场景版本和 125 个去重业务工具。本切片新增 1 个业务工具。

## 机加工到装配的整批移交

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9D-02 | 完成机加工，移交两批在制品，分笔装配报工，再冲销和重新耗用 | 冻结路线限制移交目标，工单冻结阻止移交。报告耗用整批、核对件数并继承序列号。幂等重试、错误操作和重复耗用不改变状态；下游报工冲销后在制批次可重新耗用。 |
| P9D-03 | 在浏览器移交机加工批次，再完成装配报工 | 查询返回实际目的工序、耗用报告编号和原序列号。 |

`cnc@36` 新增 `move_wip`。机加工完工后，按冻结路线整批移交到装配工序。目标工序开工前须有可用的已移交批次，装配报工使用 `wip_inputs` 指定整批投入，批次件数之和须等于报工量。已移交的源报工存在依赖，直接冲销会被拒绝。冲销下游报工解除其耗用，并保留移交和原报工记录。移交撤销、拆合及跨行业复验待后续切片。

运行时工具搜索核对 74 个场景版本和 126 个去重业务工具。本切片新增 1 个业务工具。
