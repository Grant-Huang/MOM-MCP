# P15 五行业联合验收

## 同一会话切换五行业

以同一 AgentNexus 工具连接验证五个深化场景的发现、描述、读写和运行隔离。累计门禁保留前序行业专项用例。五行业同会话用例记录在 `test-results/p15-five-industry-session.json`，包含工具、请求和结构化响应。依赖的 AgentNexus 固定版本从只读检出归档到临时目录。

| 用例 | 操作 | 验收结果 |
| --- | --- | --- |
| P15-01 | 同一连接打开 CNC@49、SMT@9、按单装配@33、钣金@6、线束@6。派工调优、电子装配缺卷恢复、钣金排样纠正、线束裁线及提前放行拒绝。交替查询后关闭，再打开旧线束版本 | 五行业都能发现和执行自身工具。共享幂等键及游标按运行隔离，跨行业误用被拒。旧线束版本继续支持旧裁线工具。 |
| P15-UI | 在同一浏览器验收台打开五行业，读工单与实装，登记套料与裁线，再切回钣金 | 五个运行可切换，钣金套料及坐标仍可查询。 |

## 后续签收

补齐五行业在同一 AgentNexus 会话中的完整正常、异常和恢复任务矩阵，以及并发、版本兼容和发布签收证据。本批交付首套联合验收。
