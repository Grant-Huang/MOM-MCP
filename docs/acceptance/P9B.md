# P9B 库位、批次和收货台账

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9B-01 | 在 CNC 和装配登记、追踪和过账收货 | 固定物料版本及单位，区分待检与可用；批次、库位、余额及流水一致，重复过账不重复入账，跨运行隔离 |
| P9B-UI | 在浏览器验收台登记收货并查询库存 | 可查具体供应商批次、库位和数量；待检收货不计入可用量 |

cnc@24 与 assembly@23 开放库位、批次、收货和入库流水。每张收货单包含一行物料，收货编号为运行内稳定回执标识。先建单，再指定内部批次、供应商批次及库位，最后过账。一个内部批次对应一笔收货，可用多个内部批次记录同一供应商批次在不同库位的分配。数量采用十进制字符串，最多三位小数，单笔最大十亿个基本单位，计件须为整数，单位来自版本物料的基本单位。待检与直接可用分别计账。待检放行、按快照计算需求及接入工序发料在后续切片验收。

使用 `npm run acceptance -- P9B` 运行当期及前序回归。

本切片通过公开 MCP 核对 57 个已发布场景版本，共 111 个去重业务工具以及 8 个公开网关方法。
