# P9B 库位、批次和收货台账

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9B-01 | 在 CNC 和装配登记、追踪和过账收货 | 固定物料版本及单位，区分待检与可用；批次、库位、余额及流水一致，重复过账不重复入账，跨运行隔离 |
| P9B-UI | 在浏览器验收台登记收货并查询库存 | 可查具体供应商批次、库位和数量；待检收货不计入可用量 |

cnc@24 与 assembly@23 开放库位、批次、收货和入库流水。每张收货单包含一行物料，收货编号为运行内稳定回执标识。先建单，再指定内部批次、供应商批次及库位，最后过账。一个内部批次对应一笔收货，可用多个内部批次记录同一供应商批次在不同库位的分配。数量采用十进制字符串，最多三位小数，单笔最大十亿个基本单位，计件须为整数，单位来自版本物料的基本单位。待检与直接可用分别计账。待检放行和快照需求见下文，工序发料留待 P9C。

使用 `npm run acceptance -- P9B` 运行当期及前序回归。

本切片通过公开 MCP 核对 57 个已发布场景版本，共 111 个去重业务工具以及 8 个公开网关方法。

## 待检放行和冻结需求

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9B-02 | 检验具体收货批次并放行，再查询冻结 BOM 的需求和可用量 | 无合格证据或使用其他批次证据时拒绝放行；合法放行只改变可用量；物料需求固定引用下达版本 |
| P9B-03 | 在浏览器查看待检、测量、放行和可用量 | 合格检验前可用量为零，放行后能看到原检验和当前可用量 |

cnc@25 与 assembly@24 的 `create_inspection` 可带 `receipt_id`，使用已启用的收货检验规格。工单用于关联追溯。收货检验的失败只影响对应收货，不进入工单完工门禁。`release_receipt_inspection` 要求同一运行、同一收货的合格检验。放行保留证据和游标，不新增入库数量。

`get_material_availability` 查询指定版本的库存和待检数量。`get_material_requirements` 按已下达快照和工单数量展开 BOM，汇总同一物料版本的叶子需求并返回可用量与差额。超过本切片支持的定点精度或展开规模时返回业务拒绝。预留和工序发料属于 P9C。

在 59 个已发布场景版本的公开 MCP 目录中，去重业务工具增至 114 个，另有 8 个公开网关方法。
