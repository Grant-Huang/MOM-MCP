# P8D 公共质量门禁

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P8D-01 | CNC 和按单装配通过公开 MCP 发现、创建、分页查询和读取检验单 | 检验单绑定工单及外部规格版本，重复提交返回同一收据，过期提交和重复编号被拒绝，重连可查询原记录，其他运行不可访问 |
| P8D-UI | 在 CNC 验收台建单并搜索、读取检验单 | 浏览器通过 HTTP 桥和公开 MCP 看到相同的待检状态和规格版本 |

首个切片在 cnc@16 与 assembly@15 开放 `create_inspection`、`list_inspections` 和 `get_inspection`。检验以工单为对象，业务人员提供检验单编号和外部规格版本引用。编号在运行内唯一。规格引用在 P9A 接入主数据前作为外部标识保留。检验初始状态为 `pending`，建单校验工单、业务游标及幂等键。查询按检验单编号升序分页，可按工单过滤，读取保持业务游标和仿真时间。

当期使用 `npm run acceptance -- P8D` 执行本切片和前序回归。后续切片依次接入实测值、检验结论、不合格处置、质量冻结及放行，并验证冻结期间阻止完工和关单。SMT、钣金和线束继续使用各自现有的过程检验入口，跨车间冻结范围随质量门禁与谱系联动验收。
