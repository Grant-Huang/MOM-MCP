# P5 · 工业设备按单装配

覆盖 F08、F09、F11、F13。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

P4 通过。准备两个交期不同的订单、装配 BOM、一种合格和一种不合格的替代件及共享测试台。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P5-01 | 检查齐套，派工并完成正常装配及终测。 | BOM、实装零件、成品序列号、合格记录和交付反馈一致。 | 齐套检查与实绩 |
| P5-02 | 运行缺料变体。先试不合格替代件，再选择合格替代或调整排队优先级。 | 不合格替代被拒绝且库存不变。合格替代保存资格依据并可追溯，优先级变化可查。 | 替代校验、队列及谱系 |
| P5-03 | 使多个任务竞争同一测试台并触发终测失败；返修后重新安排测试。 | 测试台不会被超配，未通过终测不能反馈交付，复测通过后才可放行。 | 占用区间、测试记录和终态 |

## 阶段门槛

所有适用断言通过且可定位原始证据后签收。关闭测试 run 并保留版本、种子、实际调用序列和对照结果。

## 自动化证据

严格门槛 `MOM_AGENTNEXUS=../multi-agent-conv-mvp npm run acceptance -- P5 --gate` 同时复跑 P0–P4。P5 使用独立的 `configure_to_order@1` 模型、两个不同交期的工单和一座共享测试台。

- `P5-01` 核对 BOM、工位能力拒绝、实际耗料、终测完成前拒绝收集结果、实装序列号与交付反馈。
- `P5-02` 核对不合格替代拒绝且不扣库存、合格替代质保记录、DES 到货重复投影去重和优先级调整。
- `P5-03` 在两个 stdio 连接之间验证测试台互斥、重试幂等、首次失败、返修复测、占用区间、交付门禁及 DES 重放一致性。
- `P5-UI` 在浏览器走通齐套失败、合格替代、装配、终测失败、返修、复测、交付和实装追溯。报告位于 `test-results/browser.json`。
