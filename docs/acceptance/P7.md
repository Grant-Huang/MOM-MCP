# P7 · 钣金与线束扩展

覆盖 F07、F11、F12、F14。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

P6 基线通过。准备板材、套料、余料夹具，以及两类端子和多次测试记录的线束夹具。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P7-01 | 钣金按发料、套料、切割、成形、检验和余料回库运行。按规则触发缺料，改用同规格余料。 | 用合适单位核对原料面积、产出、废料和可用余料。余料可回溯到原始板材批次。 | 面积台账和谱系 |
| P7-02 | 尝试用不合格或面积不足的余料。再由规则触发设备停机并改派有能力的设备。 | 非法余料被拒绝，未扣料。停机设备不能开工，合法改派可完成并追溯。 | 拒绝、设备状态与完工证据 |
| P7-03 | 线束完成裁线、压接及导通测试；引入替代端子后触发抽检失败并返工。 | 隔离范围等于受影响序列号。复测通过后才放行。记录原端子、实际替代批次及工艺版本。 | 返工、复测与正反向追溯 |
| P7-04 | 运行五行业套件，检查新模型注册与多版本复跑；若申请独立发布，再测试干净安装和旧调用。 | 五行业并存且通过各自正常、异常和恢复用例。独立发布需额外通过兼容及旧轨迹回归。 | 完整矩阵、依赖差异及适用的兼容报告 |

## 阶段门槛

所有适用断言通过且可定位原始证据后签收。关闭测试 run 并保留版本、种子、实际调用序列和对照结果。

## 自动化签收证据

严格门槛 `MOM_AGENTNEXUS=../multi-agent-conv-mvp npm run acceptance -- P7 --gate` 会复跑 P0–P6。

- `P7-01` 由 DES 交付缺料事件，改用同规格余料。验证 1,000 mm² 投入等于 600 mm² 产出、100 mm² 废料与 300 mm² 入库余料，并追溯原板材批次。
- `P7-02` 对不合格和不足面积余料，以及不具能力和停机设备进行拒绝检验。合法改派可继续生产，重放同键切割不会重复扣料。
- `P7-03` 由模型交付端子抽检事件，精确隔离一件，对照件可继续。验证换端子、复测和放行门禁，并查询原端子、替代资格及返工版本。
- `P7-04` 在同一 MCP 会话打开五行业各两个同种子 run，对比可见事件与重放结果，验证 52 个去重业务工具。目录证据在 `test-results/five-industry-catalog.json`。旧 AgentNexus CNC 入口由 P0 严格门槛复跑。
- `P7-UI` 在同一浏览器验收台完成钣金缺料、设备停机、余料回库，以及线束抽检、返工和复测放行的两条链。报告在 `test-results/browser.json`。
