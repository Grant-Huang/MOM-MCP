# P7 · 钣金与线束扩展

覆盖 F07、F11、F12、F14。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

P6 基线通过。准备板材、套料、余料夹具，以及两类端子和多次测试记录的线束夹具。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P7-01 | 钣金按发料、套料、切割、成形、检验和余料回库运行。按规则触发缺料，改用同规格余料。 | 用合适单位核对原料面积、产出、废料和可用余料。余料可回溯到原始板材批次。 | 面积台账和谱系 |
| P7-02 | 尝试用不合格或面积不足的余料。再由规则触发设备停机并改派有能力的设备。 | 非法余料被拒绝，未扣料。停机设备不能开工，合法改派可完成并追溯。 | 拒绝、设备状态与完工证据 |
| P7-03 | 线束完成裁线、压接及导通测试；引入替代端子后触发抽检失败并返工。 | 隔离范围等于受影响序列号。复测通过后才放行。记录原端子、实际替代批次及工艺版本。 | 返工、复测与正反向追溯 |
| P7-04 | 运行五行业套件，检查新模型注册与多版本复跑；若申请独立发布，再测试干净安装和旧调用。 | 五行业并存且通过各自正常、异常和恢复用例。独立发布需额外通过兼容及旧轨迹回归。 | 完整矩阵、依赖差异及适用的兼容报告 |

## 阶段门槛

所有适用断言通过且可定位原始证据后签收。关闭测试 run 并保留版本、种子、实际调用序列和对照结果。
