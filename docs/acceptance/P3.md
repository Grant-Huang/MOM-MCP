# P3 · 公共制造能力与汽车 CNC

覆盖 F08、F09、F10、F11、F13。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

P2 通过。准备 10 件序列化泵体、来料批次、机加工/装配/终检工艺和含缺料的变体。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P3-01 | 缺料时尝试下达；按到货规则补料后下达，再修改主数据的路线版本。 | 首次拒绝包含缺少数量及位置。补料后成功，已下达工单保留原工艺快照。 | 阻塞原因、快照版本 |
| P3-02 | 先尝试跳过前序开工，再按顺序派工、领料、加工、装配、终检、关单。 | 跳序被阻止。正常流的数量、库存余额、谱系和检验记录一致。 | 实绩、台账、成品序列号及终态 |
| P3-03 | 模拟报工响应丢失并重放同键请求，再用同键换参数。并发用两个工单请求同批剩余库存。 | 重放返回原结果，改参冲突。库存不超扣，结果只留下符合规则的实绩。 | 请求键、并发顺序、台账及数量 |
| P3-04 | 制造事务提交前注入失败，随后恢复重试；再重复投递 DES 事件或干预确认。 | 失败没有部分库存与谱系写入。合法重试只产生一次影响，确认可去重。 | 事务和恢复日志、前后投影 |
| P3-05 | 分别运行来料诱饵与真实磨损。Agent 查询证据并冻结对应对象，尝试关单，再复检、维修或报废。 | 不同病因有可追溯证据。受影响对象不能越过冻结，处置后方可关单。 | 工具轨迹、评测根因、处置状态 |
| P3-06 | 从成品反查批次，再从批次查所有成品；冲销一次合法报工并复查。 | 双向集合与实际投入相符。冲销引用原记录，衍生数量、台账和追溯同步反映纠正。 | 正反向结果及原始/更正记录 |

## 阶段门槛

所有适用断言通过且可定位原始证据后签收。关闭测试 run 并保留版本、种子、实际调用序列和对照结果。
