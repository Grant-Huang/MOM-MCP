## 执行口径

- 从阶段文档指定的前置版本开始。每个用例创建独立 run。仅并发、切换与恢复用例明确共享或复用实例。
- 用例描述中的时间与顺序来自服务端。测试用种子、停止条件及模型规则控制实验。事件发生时刻由 DES 推导。
- 对成功动作断言返回值与后续查询。对拒绝动作核对稳定错误码及相关对象，同时检查业务记录、库存、可见游标和已公开历史。预期的审计记录按实际契约单独核对。
- 机械断言使用脚本执行。涉及 Agent 判断的案例另外记录其工具序列和证据，验收依据是最终业务事实与可追溯的取证过程。
- 每次执行记录源码提交、客户端/引擎/模型/场景版本、种子、命令顺序、起止游标、实际结果、期望结果及证据的位置。重放可映射新生成的 run ID，对照事件时间、相对顺序、实体引用和业务载荷。
- 每项填写通过、失败、阻塞或未执行。共享的阶段门槛要求该阶段全部必需用例通过。失败、阻塞和未执行项保留复现信息。评测侧证据与普通 Agent 工具响应分开存放。

## 证据记录模板

| 字段 | 记录内容 |
|---|---|
| 用例、执行状态 | 阶段及用例 ID、通过/失败/阻塞/未执行 |
| 输入与版本 | 提交、连接方式、版本清单、场景参数、种子 |
| 实际过程 | 脚本或工具调用序列、并发顺序或故障注入点 |
| 结果 | 逐条断言、事件游标、前后业务状态 |
| 复查 | 脱敏测试日志及相关缺陷，失败后复跑的证据 |
