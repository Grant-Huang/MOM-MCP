# P2 · 服务端时钟、随机事件与模型包

覆盖 F03、F05、F06、F07、F12、F15。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

P1 通过。准备 CNC 模型、独立最小模型和包含同时刻事件的规则夹具。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P2-01 | 两个调用端共享 A，另开 B。读取 A 两次，再用控制入口推进 A 至下一事件。 | 读取期间时间不动。A 的两个调用端在同一游标看到相同时间，B 不受影响。 | 带游标的时钟记录 |
| P2-02 | 提交到达分布和相对处理时长。用同种子复跑两次，再换用预选对照种子。 | 同输入的时间及顺序一致，对照种子的预选随机事件有变化。绝对事件时刻字段被拒绝。 | 规则输入、种子、轨迹比较 |
| P2-03 | 构造两个候选落在同一时间量化窗口；分别测试事件上限、同刻循环限制及重复读游标。 | 同刻顺序稳定，超预算返回可诊断状态。重试取数可去重且不会遗漏事件。 | 队列顺序、停止原因及游标 |
| P2-04 | 从同一场景打开对照和干预实例。在报警前安排维修，再推进两者。 | 维修开始于服务端确认的当前时刻。维修完成由规则安排，后续观测改变；已公开历史保持一致。 | 干预确认、前缀比较、未来轨迹差异 |
| P2-05 | 加载 CNC 和最小模型；尝试未知版本和无效模型参数；对照 P0 的旧 CNC 入口。 | 无需修改内核即可注册第二种模型。未知版本和非法模型参数被拒绝并返回可定位错误。兼容入口基线通过。 | 包版本、内核依赖图及回归结果 |
| P2-06 | 分别用 Agent 和评测身份查询未来轨迹、根因与运行参数。 | 两类角色的可见性符合契约。Agent 的搜索、事件与错误响应不泄露隐藏数据。 | 脱敏接口对照 |
