# P0 · AgentNexus 接入与 CNC 基线

覆盖 F01、F12。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

固定 AgentNexus 与现有 DES 提交。准备一个只读测试工具、一个可观察的受控写入工具，以及 CNC 基线夹具。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P0-01 | 启动最小 stdio 服务。通过实际 AgentNexus 配置执行初始化、发现，再由 Agent 查测试对象。 | 初始化成功。工具可见，结构化字段保留类型，并能驱动下一次查询。 | 版本、启动命令、工具目录和脱敏调用记录 |
| P0-02 | 通过同一连接执行受控写入，立即查询；随后分别传缺参和业务非法值。 | 有效写入可见。不同错误可被 Agent 区分，非法调用不改变业务对象。 | 结构化成功与错误响应、状态差异 |
| P0-03 | 让测试服务延迟响应，触发客户端超时，重建连接后用同一探针数据库查询结果。 | 超时可诊断。调用方可确定结果或通过幂等键安全重试。后续合法调用正常。 | 超时记录、后续查询及写入计数 |
| P0-04 | 用现有 CNC 服务运行固定剧本和两个种子，每组复跑；比对进程内与 stdio；执行一次维修干预。 | 同输入轨迹一致。基线包含运行参数、事件、遥测、干预和评测侧断言；普通观察不暴露标准答案。 | 归一化轨迹与比较结果 |

## 阶段门槛

所有适用断言通过且可定位原始证据后签收。关闭测试 run 并保留版本、种子、实际调用序列和对照结果。
