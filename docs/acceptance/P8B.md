# P8B 工单 · 查询、预检与单笔下达

| 用例 | 操作 | 必需断言 |
|---|---|---|
| P8B-01 | 打开 CNC 与按单装配 v3，搜索、描述并调用公共工单列表；在 CNC 预检、下达后再预检 | 相同列表契约、稳定分页、状态与详情一致；预检保持游标，已下达工单及冻结物料返回阻塞；下达与预检使用同一拒绝规则；历史版本工具目录保持兼容 |
| P8B-02 | 比较 CNC 与装配的预检契约；模拟装配缺料、替代、指定不适用工位与派工 | 同一发现契约、预检无写入；缺料与派工一致，合格替代后仅适用工位可派工 |
| P8B-03 | CNC 与装配通过同名工具预检和提交；验证缺料、幂等、游标冲突与快照 | 拒绝无写入；重放保留原结果；装配须先下达才能派工，已固化材料不可替代；旧场景继续能派工 |

P8B-UI 在浏览器验收台使用真实 MCP 验证 CNC 预检和下达，并切换到装配缺料场景，使用合格替代料恢复齐套、派工并再次预检。

执行 `npm run acceptance -- P8B` 运行当前切片及 P0–P8A 回归，通过 `--gate` 要求 AgentNexus 证据。当前切片交付工单列表、公共预检与单笔下达。其余公共写入、逐项场景裁决和跨车间验收继续在 P8B 实施。

CNC 与按单装配使用新增 v3 配置验证列表。旧版本保留原工具目录。列表按工单编号排序，支持状态过滤与游标分页，状态与该场景详情一致。CNC 预检返回当前路线版本和提交游标，供调用方在下达时检测状态漂移。

装配预检通过 assembly@4 和 assembly-shortage@2 开放。它按当前产品配置返回适用工位，按已确认的替代料计算缺料量。选定工位后，派工在同一事务中按实时状态重新检查；预检本身不预留物料。此前场景版本保留原目录。

公共下达通过 cnc@4、assembly@5 和 assembly-shortage@3 开放。提交必需预检得到的业务游标和幂等键。CNC 固化工艺版本，装配固化产品配置和实际选定的物料定义。下达收据统一返回 released，工单详情仍显示当前工艺执行阶段，例如 CNC 的 ready。装配派工使用固化定义并重新检查可用料及工位。下达本身不扣减也不预留库存。公共批量下达、其余状态写入及跨车间验收仍待交付。
