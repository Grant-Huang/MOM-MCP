# P8B 工单 · 查询、预检与单笔下达

| 用例 | 操作 | 必需断言 |
|---|---|---|
| P8B-01 | 打开 CNC 与按单装配 v3，搜索、描述并调用公共工单列表；在 CNC 预检、下达后再预检 | 相同列表契约、稳定分页、状态与详情一致；预检保持游标，已下达工单及冻结物料返回阻塞；下达与预检使用同一拒绝规则；历史版本工具目录保持兼容 |
| P8B-02 | 比较 CNC 与装配的预检契约；模拟装配缺料、替代、指定不适用工位与派工 | 同一发现契约、预检无写入；缺料与派工一致，合格替代后仅适用工位可派工 |
| P8B-03 | CNC 与装配通过同名工具预检和提交；验证缺料、幂等、游标冲突与快照 | 拒绝无写入；重放保留原结果；装配须先下达才能派工，已固化材料不可替代；旧场景继续能派工 |
| P8B-04 | 在已有执行记录的 CNC 和装配 run 中创建工单、改来源需求并下达 | 列表与详情可见，重复编号和装配序列号拒绝，过期游标拒绝，下达后禁止编辑，幂等重放稳定，跨进程可查且不同 run 隔离 |
| P8B-05 | CNC 与装配提交包含可下达、缺料、未知和重复工单的列表 | 按输入顺序返回结果；只有成功项推进游标，重复提交返回原收据，换参复用幂等键冲突，全部拒绝时游标保持 |
| P8B-06 | CNC 与装配在派工后暂停和恢复。暂停期间尝试执行，CNC 额外验证设备停机阻止恢复 | 查询显示 held 和原因，执行拒绝且无写入，恢复回到原阶段，游标及幂等重放正确 |
| P8B-07 | CNC 和装配取消未执行工单，拒绝取消有投入的工单，通过质量门禁后确认完工并关单 | 取消原因可查，拒绝不推进游标，完工和关单分别提交，装配交付前关单受阻，重试保留原收据 |
| P8B-08 | CNC 下达以后调整装配工作中心，经机加工向装配交接 | 老工单继续使用固化工作中心，拒绝跳序和错派。新工单使用新版本，执行台账保留两次派工与路线版本 |

P8B-UI 在浏览器验收台使用真实 MCP 验证 CNC 草稿创建、更新、预检、下达、暂停、恢复、完工和关单，并切换到装配缺料场景，使用合格替代料恢复齐套、批量下达、重放并派工。

执行 `npm run acceptance -- P8B` 运行当前切片及 P0–P8A 回归，通过 `--gate` 要求 AgentNexus 证据。当前切片交付工单列表、公共预检、单笔下达和草稿写入。本页覆盖工单状态写入和最小跨车间路线。各工艺契约审查见 [分层审查](../MCP_LAYERING_REVIEW.md)。

CNC 与按单装配使用新增 v3 配置验证列表。旧版本保留原工具目录。列表按工单编号排序，支持状态过滤与游标分页，状态与该场景详情一致。CNC 预检返回当前路线版本和提交游标，供调用方在下达时检测状态漂移。

装配预检通过 assembly@4 和 assembly-shortage@2 开放。它按当前产品配置返回适用工位，按已确认的替代料计算缺料量。选定工位后，派工在同一事务中按实时状态重新检查；预检本身不预留物料。此前场景版本保留原目录。

公共下达通过 cnc@4、assembly@5 和 assembly-shortage@3 开放。提交必需预检得到的业务游标和幂等键。CNC 固化工艺版本，装配固化产品配置和实际选定的物料定义。下达收据统一返回 released，工单详情仍显示当前工艺执行阶段，例如 CNC 的 ready。装配派工使用固化定义并重新检查可用料及工位。下达本身不扣减也不预留库存。

草稿写入在 cnc@5、assembly@6 开放。创建使用场景原始参考工单及来源需求，装配填写唯一序列号。CNC 继承该场景的通用执行定义，装配继承参考工单的配置与交期偏移。草稿更新当前只允许改来源需求，适用于本工具创建且仍处于 planned 的工单。创建和更新使用业务游标与幂等键，在同一事务提交。下达后详情保留来源需求与参考工单，

批量下达在 cnc@6、assembly@7 和 assembly-shortage@4 开放。每次提交 1–50 个工单，须带批次幂等键与预期业务游标。逐项复用单笔下达规则，同一编号的后续出现返回 DUPLICATE_WORK_ORDER。业务拒绝可与成功项同批返回，底层事务失败会回滚整批。批次收据与成功项同事务持久化，同键同参重放原收据。

暂停与恢复在 cnc@7、assembly@8 开放，分别使用 hold_work_order 和 resume_work_order。暂停理由属于工单执行，不改变质量冻结、已发物料或历史实绩。恢复回到原执行阶段，并重新检查当前适用的物料、设备与质量门禁。装配测试已占用测试台时拒绝暂停，待 P8C 定义活动测试的中断语义。

取消、完工确认及关单在 cnc@8 和 assembly@9 开放。取消仅适用于无执行投入的工单。CNC 已领料或有生产实绩、装配已有实装或测试实绩时，返回 ORDER_HAS_EXECUTION。CNC 检验处置通过后可确认完工，装配测试通过后可确认完工，交付完成后可关单。公共完工确认保留工艺阶段和实绩，关单写入终态。CNC 新版仅暴露公共关单，旧场景保留 close_order。公共库存入库联动待 P9D 验收。

最小跨车间链路在 cnc@9 开放。下达冻结工序顺序和工作中心。修订后的执行定义只用于后续下达，历史版本号不能重用。派工核对快照并记台账，工序完成后才能派往下一环节。该链路验证路线交接与订单状态。跨车间库存移动、合批拆批、涂装冻结和分配在 P9D 综合门槛验收。
