# P6 · 三行业基线交付

覆盖 F01–F13、F15。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

P0–P5 必需用例通过。在干净环境部署指定版本，准备 AgentNexus 和介绍页。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P6-01 | 同一 AgentNexus 连接打开三个行业，交替完成工具发现、取证、一个处置动作和复查。 | 每行业可用工具准确，运行 ID、时钟、证据及动作结果互不串线。 | 三条真实客户端工具轨迹 |
| P6-02 | 每行业执行正常链和异常链，并用固定种子复跑；选取不同种子运行变体。 | 完整链、拒绝及恢复满足 P3–P5；随机变体仍满足库存、状态、可见性等不变量。 | 行业签收矩阵、轨迹和不变量结果 |
| P6-03 | 模拟重启后恢复，以及权限错误、超预算、并发和运行关闭。 | 复跑或恢复不重复产生业务记录。权限及预算错误可诊断，关闭在其他 run 上无副作用。 | 恢复、并发和资源报告 |
| P6-04 | 在窄屏和桌面用键盘查看 index；根据说明找到连接步骤、场景与示例。 | 页面清楚说明项目目的、共享时钟、Agent 用法与发布状态。导航、文档链接及代码示例可读。 | 页面检查结果与说明核对 |

## 阶段门槛

所有适用断言通过且可定位原始证据后签收。关闭测试 run 并保留版本、种子、实际调用序列和对照结果。
