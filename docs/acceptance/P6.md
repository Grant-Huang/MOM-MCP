# P6 · 三行业基线交付

覆盖 F01–F13、F15。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

P0–P5 必需用例通过。在干净环境部署指定版本，准备 AgentNexus 和介绍页。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P6-01 | 同一 AgentNexus 连接打开三个行业，交替完成工具发现、取证、一个处置动作和复查。 | 每行业可用工具准确，运行 ID、时钟、证据及动作结果互不串线。 | 三条真实客户端工具轨迹 |
| P6-02 | 每行业执行正常链和异常链，并用固定种子复跑；选取不同种子运行变体。 | 完整链、拒绝及恢复满足 P3–P5；随机变体仍满足库存、状态、可见性等不变量。 | 行业签收矩阵、轨迹和不变量结果 |
| P6-03 | 模拟重启后恢复，以及权限错误、超预算、并发和运行关闭。 | 复跑或恢复不重复产生业务记录。权限及预算错误可诊断，关闭在其他 run 上无副作用。 | 恢复、并发和资源报告 |
| P6-04 | 在窄屏和桌面用键盘查看 index；根据说明找到连接步骤、场景与示例。 | 页面清楚说明项目目的、共享时钟、Agent 用法与发布状态。导航、文档链接及代码示例可读。 | 页面检查结果与说明核对 |

## 阶段门槛

所有适用断言通过且可定位原始证据后签收。关闭测试 run 并保留版本、种子、实际调用序列和对照结果。

## 自动化签收证据

使用 `MOM_AGENTNEXUS=../multi-agent-conv-mvp npm run acceptance -- P6 --gate`，执行 P0–P6。部署及资源预算见 [三行业基线](../RELEASE.md)。

| 用例 ID | 证据 |
|---|---|
| `P6-01` | 同一个 AgentNexus MCP 连接在 CNC、SMT 和按单装配间交替发现工具、读取证据、执行写入并复查。记录在 `test-results/agentnexus-industries.json`，固定 AgentNexus 版本见 P0 验收。 |
| `P6-02` | CNC、SMT 与装配各执行两次种子 42、一次种子 17。相同种子的时间线和业务结果相同，变化种子的事件不同且仍满足业务不变量。证据在 `test-results/industry-replay.json`，正常链同时由 P3–P5 复跑。 |
| `P6-03` | 终测调度后终止 stdio 进程，从同一数据库恢复并重放写请求，只出现一个终测完成事件。另验预算边界、Agent 工具隔离、并行读取和关闭分离。证据在 `test-results/restart-recovery.json`。 |
| `P6-04` | 桌面和手机视口以键盘导航首页，检查文档和示例配置真实可读。 |
| `P6-UI` | 浏览器单页切换三个独立 run，使用同一幂等键验证不串线，执行处置后逐一关闭。浏览器签收报告统一位于 `test-results/browser.json`。 |

部署指南和工具目录覆盖三个已交付行业。钣金与线束是 P7 的后续场景。
