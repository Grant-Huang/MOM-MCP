# P1 · 工具目录与场景隔离

覆盖 F02、F03、F04、F08。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

P0 通过。准备两个能力有差异的场景及一个不合法的场景定义。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P1-01 | 用“质量冻结”和 quality hold 搜索，分别限制业务域和读写类型，重复执行。 | 同义词命中相同业务工具。过滤准确且排序稳定。工具属于相应 run 的能力集合。 | 查询、排序和场景能力快照 |
| P1-02 | 描述工具后按返回 schema 发起合法调用，再试缺参、未知工具及另一场景专属工具。 | 描述与运行校验一致。拒绝返回可区分的错误，业务状态保持原状。 | schema、正常与失败响应 |
| P1-03 | 同连接打开 A、B。对 A 冻结一批物料后交替查询 B、A；结束 A 后再查询两者。 | 仅 A 受冻结和关闭影响。两个实例的对象、时钟和游标可独立查询。 | run ID、各实例前后快照 |
| P1-04 | 提交合法定义，再试悬空引用、非法结构及直接指定发生时刻。模型版本和参数语义在 P2 校验。 | 合法定义可注册。错误指出具体字段，非法定义无法打开。 | 验证结果与场景目录 |

## 阶段门槛

所有适用断言通过且可定位原始证据后签收。关闭测试 run 并保留版本、种子、实际调用序列和对照结果。

## 回归证据

严格门槛执行 `MOM_AGENTNEXUS=../multi-agent-conv-mvp npm run acceptance -- P1 --gate`，同时复跑 P0。P1 验收中的 `clock` 为固定夹具初始值，`cursor` 仅反映当前实例的模拟写入。P2 接入共享时钟和事件驱动游标。

| 用例 ID | 验证入口和证据 |
|---|---|
| `P1-01` | Rust stdio 验证英中同义词、读写和业务域过滤，以及多次查询的稳定排序。 |
| `P1-02` | Rust stdio 核对描述 schema、缺参、未知和不可用工具，以及冻结与幂等键冲突。 |
| `P1-03` | 同一数据库上的两条 stdio 连接验证 run 隔离、关闭、跨连接复查和游标。 |
| `P1-04` | 可信 CLI 验证悬空引用、非法结构、显式发生时刻和版本覆盖被拒绝，合法定义可以经 MCP 打开。 |
| `P1-UI` | Playwright 在浏览器切换 CNC 与 SMT 实例，覆盖发现、描述、错误恢复、写入及隔离后的复查。报告位于 `test-results/browser.json`。 |
