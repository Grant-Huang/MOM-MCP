## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P1-01 | 用“质量冻结”和 quality hold 搜索，分别限制业务域和读写类型，重复执行。 | 同义词命中相同业务工具。过滤准确且排序稳定。工具属于相应 run 的能力集合。 | 查询、排序和场景能力快照 |
| P1-02 | 描述工具后按返回 schema 发起合法调用，再试缺参、未知工具及另一场景专属工具。 | 描述与运行校验一致。拒绝返回可区分的错误，业务状态保持原状。 | schema、正常与失败响应 |
| P1-03 | 同连接打开 A、B。对 A 冻结一批物料后交替查询 B、A；结束 A 后再查询两者。 | 仅 A 受冻结和关闭影响。两个实例的对象、时钟和游标可独立查询。 | run ID、各实例前后快照 |
| P1-04 | 提交合法定义，再试悬空引用、未知模型、非法参数及直接指定发生时刻。 | 合法定义可注册。错误指出具体字段，非法定义无法打开。 | 验证结果与场景目录 |
