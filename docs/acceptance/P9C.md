# P9C 预留、拣料与工序发料

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9C-01 | CNC 与装配对冻结需求预留批次，并发争用同一库存，拣料后撤拣与释放 | 总预留不超过批次可用量或工单需求；排除待检和错版本；重试返回原收据，拣料及撤拣不扣实物 |
| P9C-UI | 在浏览器预留已入库批次，拣料、撤拣并释放 | 可查关联的工单和库位，可用量在释放后恢复 |

cnc@26 与 assembly@25 开放 `reserve_material`、`list_reservations`、`release_reservation`、`pick_material` 和 `unpick_material`。预留绑定已下达工单与实际批次，数量用与收货相同的定点口径。预留及拣料均占用可用量；撤拣恢复为预留，释放返还可用量。拣料期间须先撤拣再释放。在库量等到工序发料才变更。所有变更保存收据并使用业务游标。

下一切片接入工序发料和部分报工的投入记录，随后补齐退料、转储和冲销。使用 `npm run acceptance -- P9C` 运行累计验收。

通过运行时公开 MCP 枚举 61 个场景版本，去重业务工具为 119 个，本切片增加 5 个，另有 8 个公开网关方法。
