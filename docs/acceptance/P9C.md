# P9C 预留、拣料与工序发料

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9C-01 | CNC 与装配对冻结需求预留批次，并发争用同一库存，拣料后撤拣与释放 | 总预留不超过批次可用量或工单需求；排除待检和错版本；重试返回原收据，拣料及撤拣不扣实物 |
| P9C-UI | 在浏览器预留已入库批次，拣料、撤拣并释放 | 可查关联的工单和库位，可用量在释放后恢复 |

cnc@26 与 assembly@25 开放 `reserve_material`、`list_reservations`、`release_reservation`、`pick_material` 和 `unpick_material`。预留绑定已下达工单与实际批次，数量用与收货相同的定点口径。预留及拣料均占用可用量；撤拣恢复为预留，释放返还可用量。拣料期间须先撤拣再释放。在库量等到工序发料才变更。所有变更保存收据并使用业务游标。

工序发料见下文。下一切片接入部分报工的投入记录，随后补齐退料、转储和冲销。使用 `npm run acceptance -- P9C` 运行累计验收。

通过运行时公开 MCP 枚举 61 个场景版本，去重业务工具为 119 个，本切片增加 5 个，另有 8 个公开网关方法。

## 工序发料

| 用例 | 操作 | 通过断言 |
|---|---|---|
| P9C-02 | CNC 和装配从已拣料批次向已派工工序发料 | 发料原子扣减在库量并登记工序流水；拒绝错工序、冻结及重复扣账；可用余额与需求不重复计算 |
| P9C-03 | 在浏览器记录工序发料并查看库存流水 | 可查工单、工序、库位、实际批次和发料数量 |

cnc@27 与 assembly@26 开放 `issue_material_to_operation`。每笔已拣料预留可整笔发料一次。工序及工作中心须与下达快照一致，且工序已派工或正在执行。质量门禁阻断发料，发料后记录可通过 `list_inventory_movements` 的 `movement_type=issue` 查询。现有报工仍使用行业适配，后续切片接入发料引用及防止重复扣料。

本切片通过运行时公开 MCP 核对 63 个已发布场景版本，共 120 个去重业务工具及 8 个公开网关方法。
