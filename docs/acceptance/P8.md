# P8A · 公共事务与 CNC 部分报工

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P8-01 | 同工序分两笔报工，中间尝试跳序、超量、重放及冲销 | 部分报工后保持运行；重放不多扣；超量不改变状态；冲销仅恢复对应数量；工序累计达标后可派工 | 业务游标、实绩、批次谱系和台账 |
| P8-02 | 分别调用公开和评测 stdio，检查目录、开场景、运行查询和直呼控制工具 | 公开接口无种子、模型、mock 标记与诊断；评测控制仍能设置种子及重放 | 目录和结构化响应 |

P8-UI 在 CNC 验收台打开 `cnc@2`，执行两笔部分报工和一次冲销，并查询库存和实绩。历史调用可省略 `quantity`，服务会申报工序剩余量。P8 夹具仍使用单原料批次，工单跨批投入和质量门禁联动在 P9–P10 交付。

## 运行验收

```sh
MOM_AGENTNEXUS=../multi-agent-conv-mvp npm run acceptance -- P8 --gate
```

严格门槛同时复跑 P0–P7。测试检查跨历史报工的序列号分配，冲销记录继续保留，补报生成的新序列号不复用冲销记录。浏览器报告位于 `test-results/browser.json`。

P8 当前流水线只覆盖已交付的 P8A。P8B–P8D 的公共执行及质量门禁仍在计划中，见 [公共验收设计](COMMON_MES_GATE.md)。
