# P8–P9 公共 MES 验收设计

当前仅历史 P8A 用例已执行。以下用例需在实施每个批次前接入 feature map、Rust 集成与对应 Playwright 流程。使用真实 MCP 链路调用契约兼容的 mock，实现及验收均以 mock 范围为准。

| 验收组 | 关键操作 | 必需断言 |
|---|---|---|
| P8B 工单生命期 | 同批混入缺料、无权限、重复及可下达工单。依次尝试暂停、恢复、取消、完工和关单 | 预检无写入，逐工单稳定状态及错误码，拒绝没有部分副作用。历史 P8A 仍兼容。 |
| P8C 工序与并发 | 后序先开工、争抢同一能力资源、运行中改派、分批报工与超量、过期版本和幂等重试 | 先后关系和互斥有效，累计达标前不可完工，冲销后正确恢复数量并保留原审计。 |
| P8D 质量门禁 | 超限测量后冻结，尝试接收和关单；经复检、让步或报废处置再查询 | 未处置不能放行，检验和处置历史保留。同一 run 外的数据不可读写。 |
| P9A 版本、单位与变更 | 先发旧版本工单，再激活新版；构造级联 BOM 引用环、重叠生效区间和无效单位 | 拒绝非法版本，旧工单快照保持，影响评估可追踪。新工单用新版。 |
| P9B 收货与可用量 | 同一物料两个库位和批次，部分收货待检、部分合格、重复外部回执 | 台账、批次、库位和可用量一致。同一稳定事件游标入账一次。 |
| P9C 预留与纠正 | 两工单并发预留，分别拣料/撤拣、领退、转储和冲销。故障注入发生在事务写入中间 | 库存不为负；拒绝与失败不留部分台账；重复写请求命中原结果；正确恢复原库位。 |
| P9D 谱系与领域复用 | CNC 分两批投入并拆合 WIP，确认工序产出，尝试冲销已被消耗的投入；SMT 薄适配器用同工具完成预留与批次追溯 | 批次至序列号正反查吻合；依赖可解释；旧记录与纠正关联保留；共享 schema 与规则在两行业一致。 |

每组须运行真实 Rust MCP stdio 集成及回归，证明正常路径、至少一次拒绝，以及恢复后状态和台账一致。浏览器使用真实 HTTP 桥及 MCP 完成可交付的任务链。最终签收保留 AgentNexus 轨迹、共享工具契约、实际行业调用证据、提交及模型版本，并区分通过、失败、阻塞和未执行。
