# P8–P9 公共 MES 验收设计

P8A–P8C 已完成当前阶段验收，包含公共工单流程、最小跨车间、公共工序执行及默认模拟路径的 DES 停机处置。P8D–P9D 仍待签收，各批实施前登记 Rust 集成和 Playwright 流程。 [P8B 验收](P8B.md) · [P8C 验收](P8C.md)

## 目录规范签收

每批在实现前提交逐项裁决与 feature map ID，审查该批工具的分层、覆盖、粒度和场景证据。覆盖五个现有场景与至少一个跨车间样例。公共项至少给出两种独立工艺的同语义证据，登记其他场景的适用性及差异。运行时验证两种工艺复用，并追踪临时 mock 依赖的替换进度。参见 [MCP 分层审查](../MCP_LAYERING_REVIEW.md)。

| 验收组及特性 | 关键操作 | 必需断言 |
|---|---|---|
| P8B（F02、F09、F10） 工单生命期 | 同批混入缺料、未知、重复及可下达工单。配置相应业务授权时还须覆盖无权限项。依次尝试暂停、恢复、取消、完工和关单 | 预检无写入，逐工单稳定状态及错误码，拒绝没有部分副作用。历史 P8A 仍兼容。 |
| P8C（F09–F11） 工序与并发 | 后序先开工、争抢同一能力资源、运行中改派、分批报工与超量、过期版本和幂等重试 | 先后关系和互斥有效，累计达标前不可完工，冲销后正确恢复数量并保留原审计。 |
| P8D（F08–F11） 质量门禁 | 超限测量后冻结，尝试接收和关单；经复检、让步或报废处置再查询 | 未处置不能放行，检验和处置历史保留。同一 run 外的数据不可读写。 |
| P9A（F08–F10） 版本、单位与变更 | 先发旧版本工单，再激活新版；构造级联 BOM 引用环、重叠生效区间和无效单位 | 拒绝非法版本，旧工单快照保持，影响评估可追踪。新工单用新版。 |
| P9B（F08、F10） 收货与可用量 | 同一物料两个库位和批次，部分收货待检、部分合格、重复外部回执 | 台账、批次、库位和可用量一致。同一稳定事件游标入账一次。 |
| P9C（F08、F10、F11） 预留与纠正 | 两工单并发预留，分别拣料/撤拣、领退、转储和冲销。故障注入发生在事务写入中间 | 库存不为负；拒绝与失败不留部分台账；重复写请求命中原结果；正确恢复原库位。 |
| P9D（F04、F08–F11、F14） 谱系与领域复用 | CNC 分两批投入并拆合 WIP，确认工序产出，尝试冲销已被消耗的投入；SMT 薄适配器用同工具完成预留与批次追溯 | 批次至序列号正反查吻合；依赖可解释；旧记录与纠正关联保留；共享 schema 与规则在两行业一致。 |

每组须运行真实 Rust MCP stdio 集成及回归，证明正常路径、至少一次拒绝，以及恢复后状态和台账一致。浏览器使用真实 HTTP 桥及 MCP 完成可交付的任务链。最终签收保留 AgentNexus 轨迹、共享工具契约、实际行业调用证据、提交及模型版本，并区分通过、失败、阻塞和未执行。

## 临时依赖与验收执行

P8B/C 的 BOM、路线、库存适配器暂读已有夹具。P9A 用版本主数据及快照替换 BOM/路线，P9B/C 用公共库位、批次与移动台账替换库存，P9D 验证投入、实绩、质量和谱系在共享状态闭合。每次替换对同一契约重跑成功、拒绝、重试和对账。

每批验收台都能走完当期流程和此前开放的流程。feature map 登记 Rust、Playwright 入口、适用场景与临时依赖；执行器当前按阶段累计运行至 P8D，首个质量切片见 [P8D 验收](P8D.md)。后续批次随契约冻结注册阶段入口并回归前序。缺映射、未执行或测试被跳过保留为未签收。

## P10 前置门槛

在同一个 CNC run 内，通过公共 MCP 先激活并选用 BOM/BOP 与检验规格版本，下达并固化快照，再从两个库位及批次预留、发料和分笔报工。使一笔投入或产出检验不合格，查询受影响的 WIP、批次与序列号，确认放行和关单被阻止。按依赖规则纠正对应记录，补料、复检，再完工入库及关单。

最终核对工艺快照、在制量、报工实绩、原批次和库位账、检验处置与正反向谱系。原记录及纠正链必须可查，重试不能重复扣料。用 SMT 薄适配器以同名公共工具和同一 schema 重复验证预留、发料、冻结及追溯。另用多车间最小链路核对合批涂装后拆分移交、按实际投入确定冻结范围、未受影响工单继续流转。它与五场景的逐项设计审查共同验证公共契约边界。保留同一任务链的 MCP 调用轨迹、前后台账和验收报告。该组及前序回归全部通过后，方可开始 P10。
