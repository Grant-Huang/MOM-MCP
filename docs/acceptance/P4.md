# P4 · 电子装联 SMT

覆盖 F07、F08、F09、F11、F13。通用执行口径与证据模板见 [验收索引](README.md)。

## 前置与夹具

P3 通过。两工单共享一个料卷批次，混入对照批次。预置拼板及分板序列号、AOI 与返工路线。

## 必需用例

| 用例 | 操作 | 通过断言 | 留存证据 |
|---|---|---|---|
| P4-01 | 按流程下达、上料、贴装、AOI、分板和完工，查询一块单板及其拼板。 | 工序顺序正确，单板保留投入料卷、实际设备和分板关系。 | 执行记录及谱系 |
| P4-02 | 由召回规则生成供应商通知。读取上料历史，追溯到跨工单单板，隔离后尝试一起放行。 | 影响集合等于真正使用该批次的板卡；冻结板卡拒绝放行，对照板卡可继续。 | 规则、事件时间、实际与预期序列号集合 |
| P4-03 | 对受影响板卡分别执行返工、复检和报废。复跑相同种子并比较召回可见顺序。 | 复检合格才放行，报废不能进入良品。最终谱系保留原批次和返工记录。 | 处置结果、比较报告及模型注册记录 |

## 阶段门槛

所有适用断言通过且可定位原始证据后签收。关闭测试 run 并保留版本、种子、实际调用序列和对照结果。

## 自动化证据

严格门槛 `MOM_AGENTNEXUS=../multi-agent-conv-mvp npm run acceptance -- P4 --gate` 同时复跑 P0–P3。验证使用独立的 `smt_line@1` 模型包和 `smt@2` 夹具，DES 内核保持稳定。

- `P4-01` 验证下达前和 AOI 前的跳序拒绝、正常生产、单板到拼板/设备/飞达/料卷的实际追溯及工单完工。
- `P4-02` 从供应商召回的事件游标隔离两张工单的四块板。检查上料历史和料卷余量，确认原料卷不再可用，对照件可放行，隔离重试返回原结果。
- `P4-03` 比较相同种子的通知和 AOI 轨迹，检查受扰 AOI 不能直接判合格。验证失败复检继续冻结、合格复检可放行、报废件拒绝完工，以及原料卷与两次实际换料记录都可追溯。
- `P4-UI` 在浏览器完成生产、推进时钟、隔离、放行拒绝、换料、复检、报废和谱系复查。报告位于 `test-results/browser.json`。
