# P16 站点设置验收

首批用独立的本地进程启动只读设置服务。受信启动方通过 `settings-stdio --site SITE-A` 或 `--site SITE-B` 绑定站点。使用固定的版本 1 样本验证边界。生产连接和场景网关保持既有工具目录。验收台可以通过 `web --settings-site SITE-A --db <path>` 启用本机测试页面，再打开 `/settings`。该入口依赖受控本机进程权限，正式的连接身份接线和设置写入留待下一阶段。

| 用例 | 操作 | 验收结果 |
| --- | --- | --- |
| P16-01 | 从生产连接尝试列表、搜索、描述和调用设置工具，再以两个站点分别启动设置进程 | 生产无发现或调用权限。设置进程只返回绑定站点版本、工作中心和班次，参数不能切换站点，写工具不可用。 |
| P16-UI | 打开配置验收页，查询绑定站点，再向生产网关发出设置请求 | 页面可读工作中心与班次，生产网关拒绝，伪造站点参数无效。 |

## 草稿、校验与影响预览

受信启动方以 `settings-stdio --site SITE-A --draft-tools` 启用草稿工具。浏览器验收启动参数为 `--settings-site SITE-A --settings-drafts`。草稿由进程内存保存，包含基线版本、工作中心和班次候选清单。校验识别重复标识、失效工作中心、非法时间和跨午夜重叠。预览返回候选摘要、改动区块及预计生效范围，活动设置仍为原版本。启用和持久化留待后续交付。

| 用例 | 操作 | 验收结果 |
| --- | --- | --- |
| P16-02 | 保存跨午夜班次草稿，检查幂等、基线及作用域，再校验带重叠和无效引用的草稿 | 合法草稿可反复预览且摘要稳定。过期基线和重复键变更被拒，非法草稿显示问题。另一个站点无法读取草稿，活动设置保持原值。 |
| P16-03 | 浏览器保存、校验并预览夜班，再读取当前设置 | 预览显示更新后的夜班和生效范围，当前班次和活动版本保持原值。 |
