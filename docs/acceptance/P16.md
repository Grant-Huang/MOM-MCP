# P16 站点设置验收

首批用独立的本地进程启动只读设置服务。受信启动方通过 `settings-stdio --site SITE-A` 或 `--site SITE-B` 绑定站点。使用固定的版本 1 样本验证边界。生产连接和场景网关保持既有工具目录。验收台可以通过 `web --settings-site SITE-A --db <path>` 启用本机测试页面，再打开 `/settings`。该入口依赖受控本机进程权限，正式的连接身份接线和设置写入留待下一阶段。

| 用例 | 操作 | 验收结果 |
| --- | --- | --- |
| P16-01 | 从生产连接尝试列表、搜索、描述和调用设置工具，再以两个站点分别启动设置进程 | 生产无发现或调用权限。设置进程只返回绑定站点版本、工作中心和班次，参数不能切换站点，写工具不可用。 |
| P16-UI | 打开配置验收页，查询绑定站点，再向生产网关发出设置请求 | 页面可读工作中心与班次，生产网关拒绝，伪造站点参数无效。 |
