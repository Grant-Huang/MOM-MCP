# 五行业 MES 工具链扩展计划

## 目标和交付口径

P0–P7 已交付五行业 mock 基线。下一轮以 AgentNexus 能执行、取证和恢复的真实制造任务为验收单位。保持现有 MCP 发现、描述、调用及 run 路由，逐步把行业状态抽成共享领域能力。P8/P9 并行审查五套场景。P10–P14 再按 CNC → SMT → 按单装配 → 钣金 → 线束的顺序深化可运行场景。每次只迁移已能从接口到台账完成验收的业务链。

原规划基线为 68–106 人周，公共能力和 CNC 为 28–42 人周。该基线沿用作对比。P8B 首轮目录裁决后，按新增公共契约、跨场景数据、兼容迁移和验收成本重估 P8/P9；P9D 签收后再更新行业深化估算。有限产能优化、实时设备采集、真实 ERP/WMS/QMS/PLC 对接、跨厂高可用和合规认证独立估算。外部系统用可重复的 mock 契约表达。数量与差距见 [MES 能力边界](MES_SCOPE.md)。

### Mock 主线近期优先事项

按 [双主轴路线](IMPLEMENTATION_PLAN.md#双主轴路线与准出)，短期把 P9D 的同一 run 闭环作为验收主线。CNC 先贯通下达快照、领料、部分报工、质量冻结、纠正及台账核对。随后在装配独立运行同一公共流程并标记工艺差异。既有 P9A–P9D 依赖与 P10 前置门槛继续适用。

中期用项目方提供的开源 MES/MOM 参考整理候选工具，沿 [分层审查](MCP_LAYERING_REVIEW.md) 逐项记录参考来源、业务意图、五行业适用性、权限、异常、纠正、台账和覆盖缺口。以业务任务和异常恢复检验覆盖。DES 按场景驱动业务事件，AgentNexus 通过公开 MCP 完成观察、处置和结果复查。联调用例在中期末段进入实施。

## P8/P9 主交付

用五个已有场景与跨车间、高追溯、混流等补充情形审查工具分层、覆盖和粒度。逐批确定适合公共集的契约，再实现共享 mock 并验收。行业、履约策略与车间工艺独立配置。详见 [MCP 分层审查](MCP_LAYERING_REVIEW.md)。

| 讨论要求 | 计划落点 | 交付证据 |
|---|---|---|
| 公共层、工艺包和行业配置分层 | P8B 建立裁决目录，P8C–P9D 逐批审定 | 逐项记录业务意图、权限、副作用、纠正和跨场景适用性 |
| 生产相关 WMS/QMS 颗粒度 | P8D 审检验与处置，P9B/C 审收货、备料及纠正，P9D 验证联动 | 生产相关动作或外部回执都有明确归属、测试及台账结果 |
| 五场景及更多压力情形 | 五套既有场景加多车间、高追溯、混流。行业、履约策略、工艺独立配置 | 场景矩阵逐项反证。钣金与涂装专有能力入工艺包，公共集承载投入产出及跨车间移交 |
| 后端、验收台和临时依赖 | Rust 共享业务 mock，沿用 HTTP 至 MCP 验收台；未交付依赖按阶段替换 | 当前与前序 feature map、Playwright、Rust 测试及替换记录，签收后逐阶段 PR |
| 服务端共享时钟与公开契约 | 调用端选择场景并提供允许的配置，服务端 DES 生成时间和事件 | 公开发现、描述、调用及错误保留业务语义；仿真诊断由受信控制面验证 |

## 公共架构

| 领域 | 公共实体和不变量 | MCP 能力族 |
|---|---|---|
| 主数据与版本 | 物料、单位、BOM/BOP、工艺版本与生效点。下达快照不可改写 | 查主数据、创建/激活版本、评估工程变更、读取工单快照 |
| 生产执行 | 工单与工序实例、依赖和能力；分批报工总量守恒，终态有前置条件 | 下达预检、下达、派工、开工/暂停/恢复、部分报工、纠正、关单 |
| 物料与在制 | 库位/批次、预留和投入；库存不可负，重复写入不会多扣 | 齐套、预留、发料、退料、调拨、盘点差异、在制拆合及移动 |
| 质量与谱系 | 检验规格和记录、不合格单、处置及有效谱系；冻结阻止放行 | 创建检验、记录测量、隔离、复检、返工、报废、放行和双向追溯 |
| 资源和设备 | 工作中心能力、设备、班次、人员资质、维护状态 | 查队列、调优先级、改派、记录停机/维修、查询可用能力 |
| 集成与证据 | 工单反馈、事件游标、授权与审计；固定版本和种子可复跑 | 读事件、查询审计、查看提交结果、模拟外部回执 |

默认通过现有 SQLite 事务同时写业务状态、追加台账与幂等结果，写命令按 run 检查预期版本。跨进程的 DES 事件使用稳定 ID 和游标去重。工具描述给出阻塞条件、可能副作用及重试语义。并行多步骤动作须明确原子提交或可诊断的部分成功。评测诊断和未来事件继续隔离。

旧场景与数据库作为持续回归基线。对兼容扩展使用默认值与可选字段，改变业务语义时增加场景或契约版本。公共契约先完成多场景设计审查。实现由 CNC 起步，再用独立工艺验证复用，并逐次替换行业专用实现。按领域冻结 schema、台账不变量和故障验收，再引入行业专属约束。

## 里程碑与退出标准

| 阶段 | 工作包 | 退出标准 |
|---|---|---|
| P8 公共执行与质量门禁 | P8A 已验收部分报工；P8B 已交付公共查询及 CNC、装配预检、单笔与批量下达、草稿写入、暂停恢复、取消、完工及关单。P8B 最小跨车间路线已验证，P8C 已开通工序查询、资源能力、优先级和派工；资源占用互斥、改派、工序状态、实绩与 DES 停机处置已验证，P8D 待接入质量门禁 | 分批执行、资源竞争、暂停恢复、质量冻结与安全纠正通过公共契约验收 |
| P9 公共主数据及库存 | 版本化 BOM/BOP、工单快照、带单位的库存、库位/批次预留、领退和在制 | 两批次供料可并发，冲销恢复对应库位且不损坏其他报工；冻结后的工艺快照可查询 |
| P10 CNC 深化验收 | 多工序依赖、换机换刀、首件/过程检验、质量处置、工序级谱系和关单 | 跨两批次部分报工并遇质检拒绝，补料、冲销、复检后完成；库存、WIP、实绩和谱系一致 |
| P11 SMT 深化 | 公共库存和工序复用，料卷拆接、飞达、拼板、AOI 复判、召回 | 隔离集合由实际投料推导，跨工单拆分与返工可追溯，未受影响件继续 |
| P12 按单装配深化 | 配置 BOM 与变更生效、替代资格、并发资源、实装清单、测试版本 | 两份配置共享资源并处理变更、失败返修和序列化交付 |
| P13 钣金深化 | 多订单套料、尺寸等级、余料预留、消耗分摊、模拟套料服务 | 多工单领用同板可按面积核算，余料可在后续工单复用并追溯 |
| P14 线束深化 | 裁线批次、端子和工装资格、分段压接、抽检、返工版本 | 多端子线束可定位受影响端点，返工复测完整保留版本和实际投入 |
| P15 五行业签收 | 同一 AgentNexus 会话、正常/异常/恢复、版本兼容、并发、发布 | 五行业各有可复跑的任务矩阵，每个计划用例均有工具调用轨迹及业务断言 |

P8B–P9D 的工具目录、数据设计及阶段门槛见 [公共 MES 详细设计](COMMON_MES_DESIGN.md) 与 [公共验收门槛](acceptance/COMMON_MES_GATE.md)。P8C 已合并。P8D 已在 CNC 与装配接入公共检验单、测量、结论、不合格处置、冻结和放行。P9A 在 CNC 与装配接入版本化检验规格、物料、BOM、工艺路线、联合下达快照和工程变更对比。P9B 已接入库位、批次、收货过账、待检放行及快照物料需求。P9C 已接入并发预留、拣料、撤拣、释放和工序发料。CNC 已接入发料驱动的部分报工、投入分摊和报工冲销。CNC 已接入未消耗余料退回原批次及库位。CNC 已接入整批转储及其冲销。CNC 已接入未被下游使用的收货冲销。装配已接入基于发料和冻结需求的单件报工与冲销。装配退料、发料及退料流水纠正仍待交付。跨车间的批次及在制冻结范围随 P9D 联动验证。执行器已支持 P9C 累计回归。P8C–P9D 各批在契约冻结时登记阶段入口和用例，并接入当期及前序回归。各阶段实施前冻结对应验收文档、tool schema 和 feature map。每阶段通过当前与前序回归后独立提交、推送并创建 PR。技术报表保留已实际执行的测试、通过数、场景/模型版本、种子和证据位置。工具数量属于目录统计，完成度由任务矩阵、异常路径及台账断言决定。

## P8B 写入推进顺序

1. 公共单笔下达从 CNC 与按单装配验证。版本化场景保留旧目录。预检无写入，提交复查阻塞条件、校验游标、固化执行定义并返回提交结果。 [P8B 验收](acceptance/P8B.md)
2. 工单创建及来源需求更新已接入 CNC 和装配。批量下达已复用单笔规则并验证逐项结果和重试语义。
3. 暂停与恢复已接入 CNC 和装配。取消、完工及关单已在两种工艺通过验收。P8B 已用最小跨车间路线核对下达快照。完整质量与库存联动仍按 P9D 综合门槛签收。
4. 默认模拟路径的 AgentNexus 停机处置通过 P8C-07 验收。使用服务端 DES 规则生成停机，核对事件、工单阻塞、干预回执及重放证据。外部通用连接器使用独立验收计划。 [双主轴路线](IMPLEMENTATION_PLAN.md#双主轴路线与准出)

P8C 先用 CNC 和装配验收工序读模型与待派工队列。公共资源能力、优先级和派工写入已接入。资源占用互斥和改派已接入。已接入工序开工、暂停和恢复，CNC 与按单装配的构建工序已接入公共实绩、更正和显式工序完工。默认模拟路径已覆盖 DES 停机、维修与恢复验收。下一阶段进入 P8D 质量门禁。 [P8C 验收](acceptance/P8C.md)

## P10 前置门槛

P8B–P9D 必须先在同一 run 内接通公共执行、质量、主数据、库存和谱系，并通过 [公共闭环验收](acceptance/COMMON_MES_GATE.md#p10-前置门槛)。只有模块级测试通过、工具可发现或分别完成各环节时，阶段仍处于集成验收中。P10 从已签收的公共闭环开始深化 CNC 专有能力。

## 待办 · MES 设置 MCP

为将来 AgentNexus 内服自动配置 MES，预留一组设置类 MCP。初步范围包括组织与工厂结构、工作中心与班次、编号与默认单位、工艺和质量策略默认值，以及配置模板的导入与应用。后续再明确哪些配置由 Agent 管理，并细化权限、校验、预览、启用、回滚和审计。所有设置写入模拟 MES。此待办的工具、数量和排期待定。

## 长期运营验证目标

五行业工具链最终用于测试 AgentNexus 持续运营真实工厂所需的业务判断和恢复能力。既有 83 项候选是跨场景审查输入，逐项裁决后重新统计。跨班交接、异常并发、版本与配置生效、多角色审批和回执对账纳入后续覆盖审计。详见 [长期运营测试模拟](LONG_RUNNING_MES_VALIDATION.md)。既定 P10 前置门槛继续执行。
