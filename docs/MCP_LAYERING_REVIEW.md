# P8/P9 MCP 分层、覆盖与粒度审查

P8/P9 交付经过多场景压力审查的工具规范、逐项决策目录，以及按确定的公共目录实现并验收的 mock 工具。既有 83 项是首轮输入。逐项判定保留、拆分、合并、下沉工艺包或延期，并在审查后重新统计。

## 分层

| 层 | 纳入条件 | 示例 |
|---|---|---|
| 协议与发现 | Agent 查找、理解与调用契约的跨域入口 | 搜索、描述、调用，按 run 解析可用能力 |
| 公共 MES | 两种独立工艺有同一业务意图和可共享的对象、权限、结果与状态不变量 | 下达、预留、部分收货、冻结、在制移交、追溯 |
| 可复用工艺包 | 参数或校验规则依赖特定工艺，行业场景按需启用 | CNC 刀具、SMT 拼板、钣金排样、涂装配方及固化、线束压接 |
| 企业与行业配置 | 场景间差异表达为规则和数据 | 履约策略、工艺路线、检验等级、车间与委外边界 |
| 受信控制面 | 仿真、装载与评测 | 服务端共享 DES 时钟、种子、诊断与故障注入 |

自动配置 MES 的设置类工具继续单列待办，细化时审查配置作用域、影响预览、生效、回滚和审计。公共生产工具使用已生效配置。

## 覆盖与粒度

1. 从 Agent 的任务、角色、决策和业务结果出发，按对象核对发现、预检、执行、拒绝、纠正、对账和追溯。涉及生产执行、材料可用性、质量放行或追溯结论的 WMS/QMS 事务进入公共候选。高级仓储优化、供应商质量与完整 CAPA 可审为外部业务状态或回执。
2. 独立业务意图、授权、提交边界或纠正路径是拆分依据。读、写和反向动作分别审阅。语义一致的过滤、排序和草稿字段使用参数或受约束更新。批量动作应证明逐项结果、部分成功及重试的业务价值。
3. 每个候选登记稳定标识、能力说明、参考源码、场景证据、层级与粒度裁决、复用关系、权限及前置条件、台账影响、幂等和并发、拒绝及恢复、验收 ID。公共项至少提供两个独立工艺的同语义证据，并标明五场景分别适用、存在差异或不适用的理由。
4. 每个批次先逐项裁决并冻结契约和 feature map，再实现 Rust 共享 mock。分别统计候选、评审通过、已公开、验收通过的业务操作，协议入口和旧别名单独统计。

## 跨场景压力审查

行业、履约策略与工艺独立配置。额外情形先用任务链、输入和预期台账验证设计。入选的公共契约按批次补可执行最小情形。

| 场景 | 压力任务 | 公共语义 | 工艺或配置承担 |
|---|---|---|---|
| CNC | 双批次投入、跨班部分报工 | 预留、实际发料、检验门禁、纠正和对账 | 刀具与首件策略 |
| SMT | 同料卷跨工单，拆板后发现批次异常 | 正向谱系、部分冻结、未受影响件继续 | 料卷接驳、拼板和 AOI |
| 按单装配 | 通用件备货，配置变更后再次齐套 | 生效快照、替代资格、缺料解释、实装序列号 | 配置规则和终测 |
| 钣金 | 同板跨订单，切割后形成可回用余料 | 多对多投入产出、单位守恒、余料入库 | 几何排样、折弯、余料形状 |
| 线束 | 端子分批，某端点返工 | 实际用料、局部冻结、返工与谱系保留 | 压接参数与抽检 |
| 机柜多车间 | 钣金、跨工单合批涂装、拆批装配，部分工序委外 | 合批拆批、交接责任、外部回执、异常影响范围 | 色批、配方、委外路线 |
| 高追溯离散装配 | 资格到期或批次失效，分角色检验和批准 | 对象隔离、授权放行、证据留存 | 审签与检验策略 |
| 重复混流装配 | 插单叠加线边补给延迟与设备停机 | 优先级、补料进度、跨班接续 | 节拍与补给策略 |

## 公共能力族首轮裁决

| 批次 | 公共方向及证据 | 待逐项核对的粒度 |
|---|---|---|
| P8B 工单 | CNC 与按单装配共享就绪、下达、快照、暂停恢复、完工和关单 | 批量逐项结果、撤销下达、执行中取消 |
| P8C 执行 | CNC 分批报工与 SMT 拼板实绩均需累计、拒绝超量与回退 | 发料、报工、产出的提交边界，改派与交接 |
| P8D 质量 | CNC 部分判定、SMT 召回、涂装合批拒收均影响放行 | 部分接收、复检、让步审批、返工、报废、冻结影响查询 |
| P9A 主数据 | 装配配置与线束端子规范都需要工单定义可复现 | 工艺及检验版本生效点，变更评估、激活与回滚 |
| P9B 收货 | CNC 原料和 SMT 料卷共享收货、批次绑定、待检和可用量 | 上架确认、收货更正、部分放行和状态量对账 |
| P9C 备料 | 装配提前备料和 CNC 按工序发料共享预留、拣撤、领退及转储 | 部分拣料、调拨在途、盘点差异与过账更正 |
| P9D 在制与谱系 | SMT 拆板、钣金同板多工单、涂装合批都需要多对多谱系 | 跨车间移交、外部回执、下游依赖阻断冲销 |

重点核对 Carbon 的批次绑定、有校验的拣选、撤拣、库存更正、部分检验及拒收；用 qcadoo 的报工纠正、OpenMES 的在制生效与批次处置、WebErpMesv2 的实际耗料与余料回库反证边界。逐项引用上游业务服务和运行测试，区分源码证据与待验证推断。 [开源能力附件](references/mcp/README.md)

## 实施状态与交付

当前 CNC 工具有固定路线和本地状态，其他工艺另有各自的入口。保留前序回归，逐批迁往共享状态与事务。批次交付包含公开发现和直接调用、旧入口适配及完整可操作的测试前端流程。尚未实现的后端依赖使用可替换的契约 mock。替换时验证相同的业务结果、拒绝和台账。通过 feature map、Rust 集成与 Playwright 验收后再发布阶段 PR。

本页记录规范与能力族首轮裁决。逐项契约冻结与新增公共 mock 的运行时验收由各批次完成。

## P8B 逐项审查起点

| 候选 | 初判 | 需冻结的条件 |
|---|---|---|
| list_work_orders、get_work_order | 保留两个公共查询 | 列表按状态、车间和订单筛选；详情返回确定版本、阻塞、数量和动作证据 |
| create_work_order、update_draft_order | 保留两个公共命令 | 草稿绑定来源需求；受版本保护；已下达修改走变更流程 |
| get_release_readiness、release_work_order | 保留预检与提交 | 预检无副作用，报告主数据、齐套和资源阻塞；下达重查并冻结定义 |
| release_work_orders | 保留批量候选 | 逐单权限、结果和幂等证据，复用单工单规则；测试部分成功及续跑 |
| hold_work_order、resume_work_order | 保留两个公共状态动作 | 暂停生产与质量冻结原因可分别追踪，恢复须重新检查门禁 |
| cancel_work_order | 保留公共动作 | 区分无下游实绩的取消和已有投入/产出的纠正，返回依赖 |
| complete_work_order、close_work_order | 分开建模 | 完工确认产出及质量状态，关单要求结清投入、未决异常和对账 |

P8B 优先用 CNC 和按单装配核对下达条件差异，再以机柜路线核对冻结快照是否支持跨车间和委外。现有 CNC 的 release_order 与 close_order 可作为兼容入口，mes_status 只提供当前状态线索。是否复用其实现须按快照、权限和台账约束验证。
