# MES 能力边界与设计取舍

本项目的交付单位是 AgentNexus 可重复执行和验收的制造任务链。每个场景按业务动作提供搜索和调用，关键动作有状态约束、事务与可查询证据。多个行业共用 DES 时钟、随机流、事件可见性与重放机制。业务规则、库存与谱系仍按行业演进。

P6 有 38 个去重业务工具，P7 增加 14 个，达到 52 个。直接挂载的 MCP 方法仍为 8 个。业务工具通过 `search_tools`、`describe_tool` 和 `call_tool` 使用。一个工具可能落实多个规则，也可能只对一种夹具有效。以下按任务闭环和能力边界评估。

| MES 能力 | 当前任务覆盖 | 待补深度 |
|---|---|---|
| 生产计划与派工 | 工单下达、固定工艺顺序、工位能力、共享测试台、优先级 | 多工厂与班次日历、有限产能排程、动态工序分流和插单 |
| 工艺与主数据 | CNC 下达快照、工艺修订号、线束返工版本、替代件资格 | 通用 BOM/BOP、版本生效和工程变更、电子作业指导、工装与人员资质 |
| 执行与 WIP | 整批或序列件执行、投入和报工、拒绝、重试、冲销 | 通用部分报工、拆合批、联产品、跨工位在制转移、工时与停顿 |
| 质量 | AOI、终检、导通、抽检事件、隔离、复检、报废和放行 | 通用检验计划、抽样、SPC、MRB/NCR、偏差放行和审批审计 |
| 库存与谱系 | 单批/料卷扣料、合格替代、双向谱系、面积台账和余料 | 多库位与单位换算、预留与补料、退料、库存调整、跨工单/跨工厂谱系 |
| 设备与维护 | 故障/停机事件、维修改变未来观测、设备能力和测试台互斥 | 实时设备采集、状态历史、OEE、点检、维修计划与备件 |
| 组织和集成 | 本地 MCP、浏览器验收、SQLite 及受控评测工具 | 人员角色、审批签名、ERP/WMS/QMS/PLC 集成、生产部署运维与高可用 |

## 覆盖升级的选择

五行业验证扩展能力与端到端集成。下一层深度可以先将工单/工序、物料/批次和质量处置提炼成跨行业实体，再增加部分报工、工序级追溯、资源能力与通用质量门禁。验收应以 Agent 能完成的业务任务、异常可恢复性、台账一致性及行业覆盖为准。工具数量适用于发现与发布统计。
