# 项目术语表

在 PR 与派工 Issue 正文首次使用缩写或编号时，附简短说明或链接到本表。标题和「给审查人」优先使用业务用语。

| 术语 | 含义 |
| --- | --- |
| 第 1 线 | Mock MES 工具及制造场景主线。 |
| 第 2 线 | 通用 Adapter，即真实来源系统连接与业务数据对齐主线。 |
| CH-xx | 宪章条款编号。引用其他项目条款时附原文。 |
| INTENT-xx | 产品意图审查发现编号。引用时附原发现。 |
| R-xxxx | 夜间评审台账记录编号。引用时附对应记录。 |
| GR-xx | 围栏登记编号。引用时附 [围栏登记表](governance/guardrail-registry.toml) 中的对应项。 |
| T0～T3 | 持续集成检查分层。T0 基础检查，T1 结构追踪，T2 实际执行，T3 独立语义审查或业务签收。 |
| W1～W6 | 第 6 线工作类别编号。跨项目引用须附所属项目的类别定义。 |
| L0～L3 | PR 与派工标题使用的风险等级，依次对应本仓库开发规范的 R0～R3。L0 是无行为变更，L1 是局部可逆修正，L2 涉及公共契约、共享状态或跨模块事务，L3 涉及权限、控制面、破坏性迁移或发布权。 |
| L1～L7 围栏 | 开发规范中的七层检查。引用时写出「围栏」，以区分标题中的风险等级。 |
| P14 | 线束制造场景深化阶段。 [验收](acceptance/P14.md) |
| P15 | 五行业联合签收阶段。 [扩展计划](MES_EXPANSION_PLAN.md) |
| MCP | Agent 调用工具的模型上下文协议。审查摘要优先写「业务工具」。 |
| PR | 拉取请求。 |
| Issue | 任务或问题单。 |
