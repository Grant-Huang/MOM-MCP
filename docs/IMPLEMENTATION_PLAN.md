# MOM-MCP 实施计划

项目开发治理、风险分级与围栏试点见 [七层围栏遵从计划](governance/GUARDRAIL_ADOPTION_PLAN.md)。

基线交付三个行业，扩展后达到五个行业。每个行业要有可重复运行的正常生产链、至少一个会改变 Agent 决策的异常，以及可以调用工具验证的处置结果。实施顺序按依赖与验收门槛组织。特性 ID 见 [需求与特性清单](FEATURES.md)，契约见 [架构设计](DESIGN.md)。

P0 起交付可运行的浏览器验收环境。所有里程碑均需交付当期和既有前端流程，未交付模块按计划接入可测试的 mock adapter。以 [前端验收、Mock 替换与回归计划](TEST_AND_MOCK_PLAN.md) 为共同门槛。

## P0 · Rust 骨架与端到端接入验证

- 初始化 Cargo workspace，锁定 Rust 工具链与依赖。实现 Rust 版 stdio 接入探针，按回归结果替换当前 Python 探针。记录本地启动、测试命令和 AgentNexus 测试配置。
- 先建成 Axum 静态页与浏览器验收台，经 HTTP 桥和实际 MCP stdio 完成最小读写。提供带错误和重试路径的 Rust mock adapter，配套一键启动、浏览器报告和状态重置。
- 实现 feature map 执行器和 CI，首批自动验收同时运行 Playwright、Rust 契约和集成测试。
- 在实际 AgentNexus 测试环境验证 MCP stdio 的工具发现、嵌套业务调用、结构化结果、业务错误及超时后的返回。记录使用的客户端版本。
- 固化现有 CNC 固定剧本、多个种子、干预、标准答案隔离及 stdio 一致性基线，保存归一化轨迹和预期。
- **验收**：Playwright 经浏览器验收台完成发现、读写、错误与状态复查。真实 AgentNexus 发出查询与受控写入并理解结果。旧 CNC 基线可重复运行。

## P1 · 工具目录与运行实例

- 版本化场景、初始夹具和工具 schema。实现已发布场景目录及面向可信调用端的场景校验入口。
- 实现创建、查询、结束实例以及显式 `run_id` 路由。先用最小夹具建立工单查询、物料查询及隔离动作。
- 实现 Carbon 式搜索、描述、执行，补齐同义词、过滤、稳定排序、未知工具和 schema 校验。
- **验收**：单连接交替访问两个实例，在其中一个实例隔离物料后，另一个实例的状态与可用工具保持独立。检索“质量冻结”和“quality hold”可发现同一工具并执行。

## P2 · 通用 DES 与 CNC 模型包

- 定义模型注册与选择协议，拆分通用内核、服务传输和 CNC 模型包。将磨损公式、设备参数、故障规则和固定剧本兼容逻辑迁入 CNC 包。为旧接入保留兼容入口，按轨迹基线校验。
- 实现服务端时钟、事件队列、稳定排序、标签随机流、延迟与触发模型、候选取消和干预重放。
- 实现可信调用端的场景提交、运行参数校验、预算推进、按游标读取和评测隔离。为 MOM-MCP 接上 DES 的创建、控制与事件交付。
- **验收**：同一 run 内各查询在同一游标下看到相同时间。读取不推进时间。两个 run 独立。相同输入与操作顺序重放得到同一规范化轨迹。CNC 提前维修改变未来观测，公开历史不变。一个无 CNC 依赖的最小模型可按相同接口注册。拒绝客户端指定事件时间的输入。P1 先验证场景结构和禁止字段，模型参数及版本以 P2 的服务端注册表为准。

## P3 · 制造公共能力与汽车零部件

- 实现下达快照、派工、开工、执行报工、物料事务、检验、隔离与处置、双向追溯、设备状态、关单和纠正。实现查询允许动作和阻塞原因。
- 建立运行内事务、版本冲突与幂等策略，测试跨服务干预重复送达和投影恢复。提供正常生产、来料诱饵与真实磨损三个可复跑用例。
- **验收**：泵体组件流转机加工、装配与终检。Agent 根据证据冻结受影响批次，选择复检或维修，完成处置和关单。重复报工不会多扣料，并发领料不会超扣。按原材料批次可查到确切成品序列号。

## P4 · 电子装联 SMT

- 建立料卷批次、上料位置、拼板/单板序列号和 AOI 数据。由规则生成换料、检测扰动和供应商召回，增加分板及返工谱系。
- 实现位置与批次追溯、受影响板卡隔离、返工、复检、报废及完工。用未使用可疑料卷的板卡做对照。
- **验收**：跨工单圈定受影响序列号，保留返工链条及原料关联，未受影响板卡可继续生产。新增场景无需修改 DES 内核。

## P5 · 工业设备按单装配

- 建立订单配置、装配 BOM、替代件资格、工位能力、测试台容量和成品序列号。
- 由规则生成来料延迟、测试失败与工位占用。实现齐套检查、有约束的替代、派工调整、返修和终测放行。
- **验收**：Agent 能在缺料时发现可用替代或调整优先级，不能采用未经许可的替代件。完成装配、终测和交付反馈，并查到实际使用的替代零件及其依据。

## P6 · 三行业基线交付

- 建立功能覆盖矩阵和端到端脚本，要求每行业均通过正常链及异常处置。每个模型包固定至少一条确定性回归输入，加入多种子集成检查。
- 验证三行业在同一个 AgentNexus 连接中交替运行，覆盖重复调用、权限、事件游标、并发、预算超限、关闭及重放恢复。核对标准答案与未来事件不会出现在普通 Agent 工具结果中。
- 完成面向开发者的介绍页、工具与场景目录、部署和版本兼容说明。记录连接方式、支持的版本、默认资源预算和可诊断日志。
- **交付门槛**：三行业同时通过下表；至少一次用真实 AgentNexus 客户端串起发现、诊断、执行和结果复查。保留运行记录、场景与模型版本、种子和断言证据。

## P7 · 扩至五行业并评估独立发布

- **钣金加工**：支持板材批次、套料、成形、检验及余料回库。由规则产生板材缺货或刀具停机，验收改用合格余料后，投入面积、产出、余料和废料可核对。
- **线束制造**：支持裁线、压接、导通测试、替代端子和工艺变更。由规则生成抽检失败和物料替代需求，验收隔离、返工、复测、放行及序列号追溯。
- 验证两套扩展的注册过程、跨场景搜索和重放。达到五行业后发布对应场景版本与验收证据。
- 若存在独立消费者或发布节奏需求，评估独立发布 DES 内核和模型包。先验证干净环境安装、跨版本兼容、旧轨迹重放和 AgentNexus 原有接口，之后再迁移仓库。

## 行业验收矩阵

| 行业 | 正常任务链 | 异常与处置 | 完成证据 |
|---|---|---|---|
| 汽车 CNC | 下达、领料、机加工、装配、终检、关单 | 振动与超差，查证后隔离、维修或复检 | 库存与实绩一致，序列号可双向追溯，干预改变预期未来观测 |
| 电子 SMT | 下达、上料、贴装、AOI、分板、完工 | 可疑料卷召回，按实装记录隔离、返工或报废 | 正确覆盖跨工单的受影响板卡，清洁批次可继续 |
| 工业设备装配 | 齐套、派工、装配、终测、完工反馈 | 缺料或测试拥堵，核查替代、重新派工或返修 | 替代资格可审计，测试记录和交付状态相符 |
| 钣金加工 | 发料、套料、切割、成形、检验、余料入库 | 缺料或设备停机，选用合格余料或改派 | 面积与余料台账守恒，谱系可回溯 |
| 线束制造 | 裁线、压接、测试、放行 | 压接不合格或启用替代端子，隔离后纠正 | 追溯到实际端子批次和工艺版本，复测记录可查 |

每行业记录一次成功动作、一次被规则拒绝的动作及后续恢复。每次重放校验事件顺序、业务结果和可见范围。任何关键断言未通过的行业仍计为进行中。

各阶段的输入、操作、断言和证据要求见 [分阶段验收规范](acceptance/README.md)。

P8A 及 P8B 查询、预检、单笔与批量下达和草稿写入已有阶段证据。P8B 其余写入生命周期及 P8C–P9D 公共闭环仍待完成。后续阶段以 [MES 工具链扩展计划](MES_EXPANSION_PLAN.md) 为进度来源，以 [公共验收门槛](acceptance/COMMON_MES_GATE.md) 决定何时进入 P10。
