# MOM-MCP 设计需求与特性清单

MOM-MCP 是供 AgentNexus 的 Agent 调用的离散制造 mock MCP 服务。项目演示页介绍工具和场景。工厂观察、业务动作及模拟反馈均通过 MCP 完成。这里的「完整 MES 场景」指一条可执行、可验证的制造任务链，范围以行业验收矩阵为准。

服务端时钟、由 DES 计算事件发生时间、调用端定义场景、CNC 模型包独立于内核为已确认要求。表内数量指标、工具名称和实现顺序是设计基线，待实施验证。

| ID | 特性 | 可验收结果 | 阶段 |
|---|---|---|---|
| F01 | AgentNexus 接入 | 通过实际 AgentNexus 连接完成 MCP 初始化、工具发现、查询和一次写调用，结构化结果可供下一步使用 | P0–P1 |
| F02 | Carbon 式工具发现 | 按中英文同义词、业务域和读写属性搜索。描述与执行使用同一份 schema。搜索只返回当前场景可用工具 | P1 |
| F03 | 客户端定义场景 | 调用端提交版本化场景与模型参数，包含初始状态、分布、条件和业务约束。未知模型、非法参数及直接指定事件时刻的字段均被拒绝 | P1–P2 |
| F04 | 场景选择与隔离 | 支持列出、打开、切换和结束场景。两个 run 在同一连接交替调用时各自保留数据、时钟和游标 | P1 |
| F05 | 服务端共享仿真时钟 | 一个 run 内各 Agent、模型与 MES 工具观察同一条单调虚拟时间线。读操作不推进时间。控制端只指定执行预算或停止条件 | P2 |
| F06 | 规则生成离散随机事件 | DES 按分布、状态和触发规则抽样，跳到下一事件。同行为的重放保持事件顺序。干预可重排未来事件，已公开的历史稳定 | P2 |
| F07 | 服务端模型包 | CNC 模型从通用内核依赖图移出，按包 ID 和版本加载。可在无需修改内核的情况下注册另一行业模型 | P2–P4 |
| F08 | 一致的 mock 数据 | 从初始数据和已发生事件构建工单、WIP、设备、质量、库存和谱系。任一批次的冻结及解冻在相关工具内一致可见 | P1–P3 |
| F09 | 面向 Agent 的业务动作 | 派工、开工、报工、隔离、复检、处置和关单有明确前置条件，查询可解释阻塞原因 | P3 |
| F10 | 事务、并发与重试 | 同一请求重试至多产生一笔实绩。并发领料不会超扣。版本冲突、校验失败与提交异常均有可验证的结果 | P3 |
| F11 | 追溯和纠正 | 基于实际投入与产出记录进行正反向谱系查询，冲销或补正保留原始证据 | P3–P5 |
| F12 | 重放与评测隔离 | 同场景、模型版本、种子和相同控制与动作序列可重放。Agent 看不到未来事件、根因标签与评测断言 | P0、P2–P6 |
| F13 | 三行业完整场景 | 汽车零部件 CNC、电子装联 SMT、工业设备装配均通过端到端验收，且可在同一连接切换 | P3–P6 |
| F14 | 行业扩展 | 使用相同契约扩展钣金和线束场景，分别验证套料余料谱系和替代件与测试返工 | P7 |
| F15 | 运行与维护 | 具备资源预算、运行生命周期、诊断和版本兼容测试，介绍页支持查看场景与调用示例 | P2–P6 |

相关文档见 [架构设计](DESIGN.md) 与 [实施计划](IMPLEMENTATION_PLAN.md)。
