为 AgentNexus 模拟离散制造现场

在可重复运行的制造场景中，让 Agent 查找工具、理解工况、执行模拟动作，并通过工单、库存、质量和追溯数据检查结果。

当前可查看设计和验收规范。MCP 服务及行业场景按实施计划交付。

查看 MCP 调用流程

设计原则

业务操作通过 MCP

Agent 按当前场景搜索工具、查看输入输出契约，再调用模拟查询或业务动作。

服务端共享仿真时钟

同一运行实例共享一条时间线。场景提交规则和种子，DES 推导实际事件发生时间。

结果可验证和重放

用同一份初始状态和事件记录生成业务结果。固定版本、种子及动作序列即可复跑。

行业场景规划

汽车零部件 CNC

从泵体报工与终检延伸到振动取证、批次隔离和维修干预。

电子装联 SMT

按料卷上料记录跨工单追溯受影响板卡，处理隔离、返工与复检。

工业设备按单装配

检查齐套与合格替代件，调整派工并完成终测放行。

后续扩展钣金余料追溯与线束端子替代、复测。

使用说明

以下为计划中的调用流程。AgentNexus 的实际接入配置与启动命令将在 P0 接入验证后补充。

  1. 通过 stdio 将 MOM-MCP 注册为 AgentNexus 的 MCP 服务。
  2. 调用 list_scenarios 查看场景，再通过 open_scenario 传入场景标识与可选种子，记录返回的 run_id。
  3. 按 run_id 调用 search_tools 搜索业务动作，并用 describe_tool 获取输入、前置条件和错误码。
  4. 用 call_tool 查询或执行。写操作按契约提供幂等键，随后重新查询验证结果。
  5. 打开另一场景即可获取第二个 run_id。后续请求传入目标 ID 即可切换。

搜索参数示例

{
  "run_id": "<open_scenario 返回的 ID>",
  "query": "质量冻结"
}
